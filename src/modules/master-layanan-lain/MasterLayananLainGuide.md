# Modul Master Layanan Lain

Modul ini digunakan untuk mengelola daftar layanan tindakan medis atau layanan tambahan di luar kategori utama (seperti KIA/KB).

## Fitur Utama
- **Daftar Layanan**: Menampilkan nama layanan, keterangan, dan harga.
- **Tambah/Edit**: Form untuk menginput detail layanan termasuk nominal harga.
- **Hapus**: Menghapus data master layanan.

## Struktur Data
- `nama`: Nama tindakan atau layanan (wajib).
- `keterangan`: Penjelasan mengenai layanan tersebut (wajib).
- `harga`: Nominal tarif layanan dalam Rupiah (wajib).

## Panduan Penggunaan
1. Akses menu **Master Data > Master Layanan Lain**.
2. Klik tombol **Tambah Master Layanan** untuk menambah data baru.
3. Input nama layanan, deskripsi, dan harga yang berlaku.
4. Klik simpan untuk memperbarui daftar harga layanan.
