# Modul Master Puskesmas

Modul ini digunakan untuk mengelola daftar unit Puskesmas yang terintegrasi dalam sistem.

## Fitur Utama
- **Daftar Puskesmas**: Menampilkan nama puskesmas, alamat lengkap, dan nomor telepon.
- **Tambah/Edit**: Form untuk mengelola identitas unit puskesmas.
- **Hapus**: Menghapus data unit puskesmas.

## Struktur Data
- `nama`: Nama resmi unit puskesmas (wajib).
- `alamat`: Alamat lengkap operasional (wajib, mendukung teks panjang).
- `noTelepon`: Nomor telepon kontak aktif (wajib).

## Panduan Penggunaan
1. Akses menu **Master Data > Master Puskesmas**.
2. Gunakan tombol **Tambah Puskesmas** untuk mendaftarkan unit baru.
3. Input detail identitas pada form yang tersedia.
4. Klik simpan untuk memasukkan data ke dalam daftar unit aktif.
