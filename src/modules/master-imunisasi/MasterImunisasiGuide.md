# Modul Master Imunisasi

Modul ini digunakan untuk mengelola daftar imunisasi yang tersedia di fasilitas kesehatan.

## Fitur Utama
- **Daftar Imunisasi**: Menampilkan tabel nama imunisasi dan keterangannya.
- **Tambah/Edit**: Form untuk menginput nama imunisasi dan keterangan pendukung.
- **Hapus**: Menghapus data master imunisasi yang sudah tidak digunakan.

## Struktur Data
- `nama`: Nama jenis imunisasi (wajib).
- `keterangan`: Deskripsi singkat atau kegunaan imunisasi (opsional).

## Panduan Penggunaan
1. Akses menu **Master Data > Master Imunisasi**.
2. Klik tombol **Tambah Master Imunisasi** untuk menambah data baru.
3. Gunakan tombol edit (ikon pensil) untuk mengubah data yang ada.
4. Gunakan tombol hapus (ikon sampah) untuk menghapus data.
